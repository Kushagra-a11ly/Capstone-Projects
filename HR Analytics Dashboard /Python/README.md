# 🐍 HR Analytics - Python Project

This folder contains the Python scripts used to clean, analyze, and prepare the HR dataset before building the Power BI dashboard.

## 📂 Project Structure

```
HR_Analytics_Project
│
├── data/                # Raw and processed datasets
├── images/              # Charts and generated images
├── analysis.py          # Data analysis and insights
├── dashboard.py         # Dashboard-related data preparation
├── eda.py               # Exploratory Data Analysis (EDA)
├── utils.py             # Helper functions
├── visualization.py     # Data visualization scripts
├── insights.txt         # Business insights from the analysis
└── README.md
```

## 🔧 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Tasks Performed

- Data Cleaning
- Handling Missing Values
- Removing Duplicates
- Exploratory Data Analysis (EDA)
- Salary Analysis
- Department-wise Analysis
- Employee Performance Analysis
- Attendance Analysis
- Attrition Analysis
- Feature Engineering
- Data Preparation for Power BI Dashboard

## 🎯 Project Outcome

The cleaned dataset generated through these Python scripts was used to build the interactive HR Analytics Dashboard in Power BI.
